# TopGram

Демонстрационный веб-мессенджер в тёмном оформлении, вдохновлённом привычной компоновкой Telegram.

## Возможности демо

- Список диалогов и поиск по чатам/демо-пользователям
- Личные демонстрационные чаты
- Создание групп
- Просмотр демонстрационных профилей
- Отправка сообщений внутри демо
- Сохранение демо-переписок в localStorage браузера
- Вход в аккаунт TopGram по постоянному виртуальному номеру и коду из собственного Telegram-бота
- Адаптивный интерфейс для мобильных устройств

## Запуск локально

Откройте `index.html` в браузере или используйте любой статический HTTP-сервер.

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages** и в разделе **Build and deployment** выберите **Source: GitHub Actions**. Workflow уже добавлен: `.github/workflows/pages.yml`. После следующего push или ручного запуска workflow сайт будет доступен по адресу:

`https://proveryaika.github.io/TopGram/`

## Важно

Вход в TopGram подключён к Supabase Auth, а коды входа отправляет собственный Telegram-бот. Виртуальные номера — только внутренние идентификаторы TopGram: они не принимают обычные SMS и звонки и не являются номерами Telegram. При этом переписки, группы и часть данных интерфейса пока остаются демонстрационными и хранятся в localStorage этого браузера — они не синхронизируются между пользователями или устройствами. Не вводите реальные пароли Telegram и не сообщайте коды входа другим людям.
